# Hospital Management System

## Overview

The Hospital Management System is a Java-based console application used to manage basic hospital activities such as patients, doctors, appointments, and billing.

The project demonstrates important Java concepts including OOP, collections, exception handling, file handling, and multithreading.

## Features

- Add and view patients
- Add and view doctors
- Search patients and doctors
- Book appointments
- Generate bills
- Save patient details to a file
- Exception handling
- Multithreading

## Technologies Used

- Java
- OOP
- ArrayList
- File Handling
- Exception Handling
- Multithreading
- Git and GitHub

## How to Install and Run

### 1. Install Java


java -version
javac -version
```

### 2. Clone the Repository


git clone <YOUR_GITHUB_REPOSITORY_URL>
```

### 3. Open the Project Folder


cd Hospital-Management-System
```

### 4. Compile the Program


javac main.java


### 5. Run the Program


java main
