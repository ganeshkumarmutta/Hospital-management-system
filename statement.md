# Hospital Management System – Project Statement

## 1. Problem Statement

Managing hospital information manually can be difficult and time-consuming. This project provides a simple Java-based system to manage patient, doctor, appointment, and billing information.

## 2. Scope

The system can:
- Add and view patients
- Add and view doctors
- Search patients and doctors
- Book appointments
- Generate bills
- Save patient information to a file
- Handle invalid input and exceptions

## 3. Target Users

- Hospital receptionist or staff
- Hospital administrator
- Students for academic demonstration

## 4. High-Level Features

- Patient Management
- Doctor Management
- Appointment Management
- Billing
- Search Function
- File Handling
- Exception Handling
- Multithreading
